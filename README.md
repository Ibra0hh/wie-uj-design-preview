# IEEE WIE UJ — design preview

English and Arabic snapshots of the 6 November 2026 homepage design.
Open https://Ibra0hh.github.io/wie-uj-design-preview/en/ on any device.

This repository contains only public rendered markup, styles, published images,
fonts and the client bundle needed for the animation and photo interactions.
Account and other pages link to the current live Appwrite website.
No application server, private project source, credentials, application records,
reference archives or mobile signing files are included. This is a design review
snapshot; it does not update Appwrite or imply approval of this design for Appwrite.
